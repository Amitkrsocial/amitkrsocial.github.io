# Amit Kumar — GitHub Pages Blog

A Jekyll editorial blog for `https://amitkrsocial.github.io/`.

## Publish directly on GitHub

1. Upload the contents of this folder to the root of the `amitkrsocial.github.io` repository.
2. Ensure Settings → Pages publishes from `main` and `/(root)`.
3. Wait for the GitHub Pages build in Actions to complete.
4. Add new posts in `_posts/` using the filename format `YYYY-MM-DD-your-title.md`.
5. Add valid front matter including `layout: post`, `title`, `description`, `date`, and relevant categories.

## SEO endpoints

- Sitemap: `/sitemap.xml`
- Feed: `/feed.xml`
- About: `/about/`

## Notes

This site uses GitHub Pages-compatible Jekyll plugins: `jekyll-seo-tag`, `jekyll-feed`, and `jekyll-sitemap`. Review generated URLs and metadata after deployment. The example article is a starter and should be expanded with original research and sources before publication.
